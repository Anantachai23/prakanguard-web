========================================================================
   คู่มือวิธีอัพขึ้น GitHub และ Deploy เว็บแอป PrakanGuard (ทีละขั้นตอน)
========================================================================

------------------------------------------------------------------------
[ ขั้นตอนที่ 1 : สร้างไฟล์ .gitignore ก่อนเริ่ม (สำคัญมาก!) ]
------------------------------------------------------------------------
เปิด Notepad แล้วบันทึกไฟล์ชื่อ ".gitignore" ไว้ในโฟลเดอร์โปรเจกต์นี้
โดยใส่ 3 บรรทัดนี้ลงไป:

node_modules
dist
.env

(เพื่อป้องกันไม่ให้โฟลเดอร์ขนาดใหญ่ถูกดูดขึ้นไปบน GitHub)


------------------------------------------------------------------------
[ ขั้นตอนที่ 2 : สร้าง Repository บนเว็บ GitHub ]
------------------------------------------------------------------------
1. เข้าเว็บ https://github.com แล้วล็อกอิน
2. กดเครื่องหมาย "+" มุมขวาบน -> เลือก "New repository"
3. ตั้งชื่อในช่อง Repository name เช่น "prakanguard"
4. เลือกระดับเป็น Public หรือ Private ตามต้องการ
5. ไม่ต้องติ๊ก Add README หรือ .gitignore (ปล่อยว่างไว้)
6. กดปุ่มเขียว "Create repository"
7. คัดลอก (Copy) ลิงก์ที่ได้มา เช่น:
   https://github.com/ชื่อคุณ/prakanguard.git


------------------------------------------------------------------------
[ ขั้นตอนที่ 3 : คำสั่งอัพโหลดผ่าน PowerShell / Terminal ]
------------------------------------------------------------------------
เปิด PowerShell ในโฟลเดอร์โปรเจกต์นี้ แล้วพิมพ์คำสั่งตามนี้ทีละบรรทัด:

คำสั่งที่ 1:
git init

คำสั่งที่ 2:
git add .

คำสั่งที่ 3:
git commit -m "First commit - PrakanGuard WebApp"

คำสั่งที่ 4:
git branch -M main

คำสั่งที่ 5: (เปลี่ยนลิงก์ด้านหลังเป็นลิงก์ของคุณที่ก๊อปมาในขั้นตอนที่ 2)
git remote add origin https://github.com/ชื่อคุณ/prakanguard.git

คำสั่งที่ 6:
git push -u origin main

(หากมีหน้าต่างเด้งขึ้นมา ให้กดยืนยันล็อกอิน GitHub 1 ครั้ง)
เสร็จเรียบร้อย! โค้ดทั้งหมดจะขึ้นไปอยู่บน GitHub ทันที


------------------------------------------------------------------------
[ ทางเลือกที่ง่ายกว่า : ใช้โปรแกรม GitHub Desktop (ไม่ต้องพิมพ์คำสั่ง) ]
------------------------------------------------------------------------
1. ดาวน์โหลดโปรแกรม https://desktop.github.com แล้วติดตั้ง
2. เปิดโปรแกรมแล้วล็อกอินด้วยบัญชี GitHub
3. ไปที่เมนู File -> Add Local Repository -> เลือกโฟลเดอร์นี้
4. พิมพ์ชื่อในช่อง Summary เช่น "Initial commit" แล้วกดปุ่ม Commit
5. กดปุ่ม "Publish repository" ด้านบน
เพียงเท่านี้โปรเจกต์จะขึ้น GitHub ทันทีโดยไม่ต้องพิมพ์โค้ดแม้แต่บรรทัดเดียว!


------------------------------------------------------------------------
[ วิธีนำขึ้นออนไลน์ (Deploy ให้คนอื่นเปิดดูได้ฟรี) ]
------------------------------------------------------------------------
วิธีที่ง่ายที่สุด (ผ่าน Netlify Drop):
1. เข้าเว็บ https://app.netlify.com/drop
2. ลากโฟลเดอร์ "dist" ในโปรเจกต์นี้ไปปล่อยในกรอบสี่เหลี่ยมบนหน้าเว็บ
3. เสร็จทันที! จะได้ลิงก์เว็บไซต์มาใช้งานได้ทันที มีกุญแจเขียว HTTPS ฟรี

[ ภาษาไทย ]
PrakanGuard (ปราการการ์ด) คือ ระบบสารสนเทศและเฝ้าระวังอุทกภัยผิวจราจร 6 อำเภอ จังหวัดสมุทรปราการ 
พัฒนาขึ้นโดยเยาวชนนักเรียนเพื่อสาธารณประโยชน์ ช่วยให้ประชาชนผู้ใช้รถใช้ถนนสามารถตรวจสอบ
ระดับน้ำท่วมขังบนถนนสายสำคัญ 16 พิกัด ติดตามเรดาร์ฝนและน้ำทะเลหนุนแบบเรียลไทม์ 24 ชั่วโมง 
อ้างอิงเกณฑ์มาตรฐาน ปภ. และเกจวัดระดับน้ำเทียบกับสเกลรถยนต์ พร้อมระบบแจ้งเตือนจุดน้ำท่วม
จากประชาชน (Crowdsourcing) ที่ผ่านการตรวจสอบโดยผู้ดูแลระบบ และผู้ช่วยตอบคำถามเส้นทางอัจฉริยะ (AI ChatBot)

[ English ]
PrakanGuard is a real-time road flood monitoring and hydro-meteorological information web application 
for Samut Prakan Province, Thailand. Developed by high school students for public benefit, the platform 
helps commuters track road flooding across 6 districts, monitor 24/7 rain radar and tidal surge telemetry, 
report local flood conditions via crowdsourcing with admin verification, and interact with a draggable 
smart AI information assistant.
