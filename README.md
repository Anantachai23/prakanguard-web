# PrakanGuard (ปราการการ์ด)

เว็บติดตามน้ำท่วมบนถนนใน 6 อำเภอของจังหวัดสมุทรปราการ

เว็บที่ใช้งานได้: https://prakanguard-web.vercel.app

## ที่มา

สมุทรปราการเป็นพื้นที่ต่ำติดทะเล ฝนตกหนักหรือน้ำทะเลหนุนทีไร ถนนหลายเส้นก็มีน้ำขัง คนขับรถมักไม่รู้ว่าเส้นไหนน้ำลึกแค่ไหนจนไปเจอเอง
โปรเจกต์นี้เลยรวมข้อมูลฝนกับจุดน้ำท่วมไว้ที่เดียว แล้วแสดงให้ดูง่าย ๆ บนมือถือ

## ทำอะไรได้บ้าง

- แผนที่จุดเสี่ยงน้ำท่วม 23 จุด ในอำเภอเมืองสมุทรปราการ บางพลี พระประแดง บางบ่อ พระสมุทรเจดีย์ และบางเสาธง สลับดูแบบแผนที่ถนน ภาพดาวเทียม หรือภูมิประเทศได้
- แบ่งระดับน้ำเป็น 3 ระดับตามเกณฑ์ ปภ. คือ เฝ้าระวัง (5-20 ซม.) เสี่ยงสูง (21-50 ซม.) และห้ามสัญจร (มากกว่า 50 ซม.) มีภาพเทียบความสูงน้ำกับรถเก๋ง SUV กระบะ และคนสูง 170 ซม.
- ดึงพยากรณ์อากาศและโอกาสฝนตกของแต่ละอำเภอจาก Open-Meteo และเรื่องแจ้งน้ำท่วมในสมุทรปราการจาก Traffy Fondue อัปเดตทุก 5 นาที
- คนในพื้นที่ส่งรายงานน้ำท่วมได้ บอกระดับน้ำแบบง่าย ๆ เช่น ตาตุ่ม เข่า เอว พร้อมแนบรูปและตำแหน่ง GPS รายงานจะเข้าไปที่ระบบแอดมินทันที
- มีแชทบอทตอบคำถามเรื่องสภาพอากาศ เส้นทาง และเกณฑ์ระดับน้ำ
- ใช้ได้ทั้งมือถือ แท็บเล็ต และคอม มีโหมดมืด ตัวหนังสืออ่านง่ายสำหรับผู้สูงอายุ และกดโทรสายด่วน ปภ. 1784 หรือศูนย์ของแต่ละอำเภอได้เลย

## สร้างด้วย

React 18, Vite, Tailwind CSS, Leaflet, Chart.js, Supabase และ deploy บน Vercel
ระบบแอดมินเป็น Node.js แยกอยู่ในโฟลเดอร์ `admin/`

## โครงสร้างโฟลเดอร์

```
.vscode/      ตั้งค่า VS Code (debug, tasks, extensions)
admin/        ระบบแอดมินและเซิร์ฟเวอร์ (พอร์ต 4000)
api/          Serverless function บน Vercel
  health.js         เช็กว่าระบบยังทำงานอยู่ (/api/health)
  official-flood.js ดึงจุดน้ำท่วมจาก Traffy Fondue
  sync.js           ดึงสภาพอากาศ 6 อำเภอ (แคช 3 นาที)
docs/         เอกสาร: ARCHITECTURE, SECURITY, API, DEPLOY_GUIDE
public/       ไฟล์ static เช่น โลโก้และสคริปต์ซิงก์
scripts/      สคริปต์ตรวจความปลอดภัย และไฟล์ .bat สำหรับเปิดเว็บบน Windows
src/          โค้ดหน้าเว็บสำหรับประชาชน
  components/ แผนที่ พยากรณ์ฝน ฟอร์มรายงาน แชทบอท ฯลฯ
  data/       พิกัดจุดเสี่ยงและขอบเขต 6 อำเภอ
  services/   ดึงสภาพอากาศ ซิงก์ข้อมูล และระบบความปลอดภัย
tests/        ชุดทดสอบ
  e2e/          ทดสอบหน้าเว็บบนหลายอุปกรณ์
  integration/  ทดสอบ API และเว็บที่ deploy แล้ว
  tools/        สคริปต์ช่วยหาพิกัด
```

## รันในเครื่อง

```bash
npm install
npm run dev              # เว็บหลัก http://localhost:5173
npm run admin            # ระบบแอดมิน http://localhost:4000
npm run audit:security   # ตรวจความปลอดภัยของโค้ด
npm run test:e2e         # รันชุดทดสอบ
npm run build            # build สำหรับขึ้น production
```

ถ้าใช้ VS Code กด F5 เพื่อเปิด debug ทั้งหน้าเว็บและแอดมินพร้อมกัน หรือกด Ctrl + Shift + B เพื่อเลือกคำสั่ง build, dev หรือ audit

รายละเอียดเพิ่มเติมอ่านได้ที่ [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) และ [docs/SECURITY.md](docs/SECURITY.md)
