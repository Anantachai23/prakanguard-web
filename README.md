## 🌊 เกี่ยวกับโครงการ (About Project)

จังหวัดสมุทรปราการเป็นพื้นที่ลุ่มต่ำริมแม่น้ำเจ้าพระยาและชายฝั่งอ่าวไทย เมื่อเกิดฝนตกหนักสะสมหรือน้ำทะเลหนุนสูง มักส่งผลให้ถนนสายหลักและซอยสำคัญเกิดน้ำท่วมขัง ส่งผลกระทบต่อการสัญจรและการใช้ชีวิตของประชาชน

**PrakanGuard** พัฒนาขึ้นเพื่อเป็นแพลตฟอร์มสาธารณประโยชน์ ช่วยให้ประชาชนและผู้ใช้รถใช้ถนนสามารถตรวจสอบระดับน้ำท่วม สภาพเส้นทางแบบเรียลไทม์ และคาดการณ์ฝนล่วงหน้าได้อย่างแม่นยำผ่านสมาร์ตโฟนตลอด 24 ชั่วโมง

## ✨ ฟีเจอร์หลัก (Key Features)

- 🗺️ **แผนที่จุดเฝ้าระวังน้ำท่วม 6 อำเภอ:** ครอบคลุมอำเภอเมืองสมุทรปราการ, บางพลี, พระประแดง, บางบ่อ, พระสมุทรเจดีย์ และบางเสาธง พร้อมสลับโหมดแผนที่ถนน แผนที่ภาพถ่ายดาวเทียม และแผนที่ภูมิประเทศ
- 🚦 **มาตรฐานการเตือนภัย 3 ระดับ (ปภ.):** 
  - 🟢 **ระดับเฝ้าระวัง (5 - 20 ซม.):** น้ำท่วมขังผิวจราจร รถทุกชนิดยังสัญจรได้ด้วยความระมัดระวัง
  - 🟡 **ระดับเสี่ยงสูง (21 - 50 ซม.):** ระดับน้ำท่วมครึ่งล้อ รถเก๋งขนาดเล็กควรหลีกเลี่ยง
  - 🔴 **ระดับห้ามสัญจร (> 50 ซม.):** วิกฤตน้ำท่วมสูง รถทุกชนิดห้ามผ่าน
- 🌧️ **ระบบตรวจจับฝนตกจริง & พยากรณ์ฝน 24 ชั่วโมง:** วิเคราะห์โอกาสเกิดฝนและทิศทางกลุ่มเมฆฝนรายชั่วโมง อัปเดตข้อมูลอัตโนมัติทุก 5 นาที
- 📢 **ศูนย์รับรายงานเหตุการณ์ภาคประชาชน:** ประชาชนสามารถร่วมแจ้งจุดน้ำท่วมขัง ระดับความลึก และแนบภาพถ่ายพร้อมพิกัด GPS ได้ทันที
- 🤖 **ระบบช่วยเหลืออัจฉริยะ (AI Sentry & Assistant):** ให้คำแนะนำการเดินทาง หลีกเลี่ยงจุดน้ำท่วม และค้นหาสายด่วนฉุกเฉิน
- 📱 **Mobile-First & Universal Accessibility:** รองรับการใช้งานผ่านมือถือ แท็บเล็ต และคอมพิวเตอร์อย่างลื่นไหล พร้อมโหมดมืด (Dark Mode) ถนอมสายตา

## 🛠️ เทคโนโลยีที่ใช้ (Tech Stack)

- **Frontend:** React 18, Vite, Tailwind CSS
- **Interactive Map:** Leaflet, OpenStreetMap, CartoDB, Esri Imagery
- **Icons & UI Elements:** Lucide React
- **Cloud & Deployment:** Vercel Edge Network, Supabase Realtime Database

---

## 🚀 การติดตั้งและเปิดใช้งานในเครื่อง (Getting Started)

```bash
# 1. ติดตั้ง Dependencies
npm install

# 2. เริ่มต้นรันหน้าเว็บในเครื่อง (Development Mode)
npm run dev

# 3. บิลด์สำหรับ Production
npm run build
```

เมื่อรันคำสั่ง `npm run dev` แล้ว สามารถเปิดเบราว์เซอร์ไปที่: `http://localhost:5173`
