คำชี้แจงความปลอดภัย & การใช้งาน Supabase (FAQ)

🛡️
จะโดนเรียกเก็บเงินย้อนหลังหรือไม่?
ไม่มีทางโดนเรียกเก็บเงินเด็ดขาด 100% เนื่องจากบัญชีเป็น Free Tier ที่ไม่มีการผูกบัตรเครดิตใดๆ ทั้งสิ้น และหากทรัพยากรเกิน โควตาระบบของ Supabase จะระงับการทำงาน (Pause) ชั่วคราวเท่านั้น ไม่มีการคิดเงิน
⚡
ทำไมถึงมีอีเมลเตือนการยืดเวลา/หมดอายุ?
เป็นระบบป้องกันเซิร์ฟเวอร์ค้างของ Supabase (Inactivity Pausing) ซึ่งจะแจ้งเตือนเมื่อไม่มีกิจกรรมเกิน 7 วัน แต่สำหรับ PrakanGuard มีระบบ Heartbeat Telemetry คอยซิงค์ข้อมูลผู้เข้าชมและแอดมินอยู่ตลอด ทำให้ระบบคงสถานะ Active เสมอ
🔄
หากถูก Pause จะแก้ไขอย่างไร?
หากมีการพักโปรเจกต์ เพียงแค่เข้าสู่ระบบที่ Supabase Dashboard แล้วคลิกปุ่ม Restore Project ข้อมูลทั้งหมดจะกลับมาออนไลน์เหมือนเดิมทันทีโดยไม่มีค่าใช้จ่าย
